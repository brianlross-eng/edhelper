# ED Helper v1.6 — System Distances

**Date:** 2026-07-24
**Status:** Approved under the standing overnight authorization (recommended-default
choices; user asleep). Probe-verified: `POST /api/systems/search` results carry

**Builds on:** v1.5 (Tourist + Exomastery, merged)

## Purpose

The last of the simple Spansh tools: measure straight-line distances from a
reference system to a list of other systems. Useful for picking the closest
engineer/material trader/carrier destination.

## Decisions (autonomous, recommended defaults)

| Topic | Decision |
|---|---|
| Placement | Sixth tool pill "DISTANCES". Read-only calculator: no tracker, no clipboard, no exclusion, no cockpit card. |
| UI | Reference system (ship-prefilled, editable) + textarea (one system per line, blank lines ignored) + COMPUTE. Results: table sorted by distance ascending (system, ly); unknown systems listed separately as "not found". |
| Resolution | Exact-name (case-insensitive) match against `/systems/search` (size 10), reusing the established idiom; canonical casing taken from the Spansh record. Unknown names are collected, not fatal — the tool still returns the resolvable rows. Unknown REFERENCE is fatal (`Unknown system: <name>`). |
| Limits | Max 50 target systems per computation (client-side error beyond — politeness cap on search requests). |
| Computation | Euclidean distance in ly from the record coordinates, computed in the engine host (SpanshClient), rounded for display only. |

## Architecture

1. **SpanshClient.systemDistances(req)**:
   ```ts
   interface SystemDistancesRequest { from: string; systems: string[]; }
   interface SystemDistanceRow { system: string; distanceLy: number; }
   interface SystemDistancesResult { from: string; rows: SystemDistanceRow[]; unknown: string[]; }
   ```
   Private `resolveSystemRecord(name)` returns `{ name, x, y, z } | null` via
   `/systems/search` exact-name match. Reference resolved first (throws if
   unknown); targets resolved with `Promise.all`; rows sorted ascending.
2. **Host RPC** `systemDistances`; IPC `distances:compute` (ok/error wrap);
   preload `computeDistances`; EdhelperApi method + response type.
3. **Renderer**: `SystemDistances` view (sixth pill, tool key 'distances');
   no subscriptions or active state.
