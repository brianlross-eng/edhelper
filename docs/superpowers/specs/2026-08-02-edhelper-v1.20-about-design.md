# ED Helper v1.20 — Help → About

**Date:** 2026-08-02
**Status:** Approved (Brian: "under the Help menu item, there should be an
about that'll show the version number at least").

## Context

The app never set an application menu, so it inherited Electron's stock one —
whose Help menu contains only a "Learn More" link to electronjs.org. There was
no way to see which version was installed from inside the app, which matters
now that auto-update changes it silently underfoot (and it is the first thing
any bug report needs).

## Decisions

| Topic | Decision |
|---|---|
| Menu | Custom `Menu.setApplicationMenu` with the standard roles (File/Edit/View/Window) plus a real Help menu. Keeps devtools/zoom/fullscreen roles that came free with the default menu. |
| Help contents | "About ED Helper" → message box, and a second item labelled with the version — `ED Helper <version> on GitHub` — so the version is readable WITHOUT opening the dialog. |
| About box | Version first line (what bug reports need), one-line description, then Electron/Chromium/Node build info and the repo URL. Buttons OK / Open GitHub. |
| Testability | `aboutDetail()` and `buildMenuTemplate()` are pure and unit-tested (injected `onAbout`/`onRepo`), matching the `engine-spawn.ts` / `updater.ts` convention — no Electron needed in tests. |

## Testing

Unit: about text leads with the version and carries build info + repo URL;
Help submenu contains About, both handlers fire, the GitHub item shows the
version, and the standard menus are preserved. Live: installed build, Help →
About renders "Version 1.0.11" with build details.
