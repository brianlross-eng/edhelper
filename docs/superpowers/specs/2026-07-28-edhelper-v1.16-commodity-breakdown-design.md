# ED Helper v1.16 — Show every commodity in a trade hop

**Date:** 2026-07-28
**Status:** Approved (Brian: "it says 66t imperial slaves +1 more... I can't
find out what the +1 more is" — the other commodity was Battle Weapons, only
discoverable by querying the API by hand. Unusable as shipped.)

## Root cause

`mapResult` (v1.1) collapses Spansh's per-hop `commodities[]` into a display
string — `` `${top.name}${extra > 0 ? ` +${extra} more` : ''}` `` — and DROPS
the other entries. The API returns everything we need per commodity
(`name, amount, source_commodity.buy_price, destination_commodity.sell_price,
total_profit`); we simply throw it away at mapping time. Two further confusions
from the same convention: `units` is the HOP total (66 t) while the label names
only the lead commodity, and `buyPrice`/`sellPrice` describe the lead only —
so "66t imperial slaves" reads as 66 t of slaves when it was 33 t + 33 t.

## Decisions

| Topic | Decision |
|---|---|
| Engine | `Hop` gains optional `commodities?: Array<{ name; units; buyPrice; sellPrice; profit }>` (additive; engine-planned hops leave it undefined). Existing fields keep their meaning for compatibility. |
| Host | `mapResult` populates it from every entry in the API's `commodities[]`, lowercasing names to match the existing `commodity` convention. The summary string stays as-is (the breakdown supersedes it in the UI). |
| UI | Both the plan preview and the active checklist list EVERY commodity under the hop row: "33 t imperial slaves · buy 1,745 → sell 16,474 · +486,057 cr" per line (`data-testid="hop-N-commodity-M"`). When a hop has a breakdown, the row's headline shows the hop total as "66 t total" instead of implying it's all one good. Single-commodity hops render one line (no "+N more" anywhere). Hops without a breakdown (engine-planned) render exactly as today. |
| Release | v1.0.6. |

## Testing

Host: fixture-backed multi-commodity hop → breakdown length/values/order match
the raw response (trade fixture has multi-commodity hops). UI: multi-commodity

breakdown-less hop unchanged. Live smoke: real multi-commodity plot.
