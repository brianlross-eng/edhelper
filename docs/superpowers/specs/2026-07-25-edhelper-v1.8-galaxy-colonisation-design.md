# ED Helper v1.8 — Galaxy Plotter + Colonisation Plotter (final Spansh tools)

**Date:** 2026-07-25
**Status:** Approved under the standing overnight authorization. Probe-verified —
see the "Galaxy plotter routes" and "Colonisation routes" sections of
`docs/superpowers/notes/2026-07-24-spansh-api-findings.md` and fixtures

**Builds on:** v1.7 (Community Goals, merged)

## Probe findings that shape the design

- **Galaxy Plotter** = Spansh's `/exact-plotter` page → `POST /api/generic/route`.
  Takes **id64s** (`source`/`destination`, resolved via the existing
  `searchSystemRecord`). **No jump-range param** — range comes from an 8-field
  FSD fuel model (`fuel_power, fuel_multiplier, optimal_mass, base_mass,
  tank_size, internal_tank_size, max_fuel_per_jump, range_boost`) plus
  `reserve_size`, `cargo`, toggles (`is_supercharged, use_supercharge,
  use_injections, use_injections_when_required, exclude_secondary,
  refuel_every_scoopable`), `max_time` (60), `algorithm`
  (`fuel|fuel_jumps|guided|optimistic|pessimistic`), `supercharge_multiplier`
  (4), `injection_multiplier` (2). `ship_build` optional (omitted). Inline
  `{status:'error'}` submit branch. Result `result.jumps[]` (source = entry 0),
  per jump: `name, distance, distance_to_destination, fuel_in_tank, fuel_used,
  has_neutron (bool), is_scoopable (bool), must_refuel (bool), must_inject
  (int)`. No aggregates.
- **Colonisation Plotter** = `/colonisation` → `POST /api/colonisation/route`.
  Params are exactly `source_system` + `destination_system` (system **names**).
  Result `result.jumps[]` with per-waypoint `name, distance,
  distance_to_destination, body_count, estimated_scan_value,
  estimated_mapping_value, landmark_value` (0 when none, not null); hops capped
  ~15 ly (colonisation claim range). **TRAP**: unreachable pairs still complete
  with `result.incomplete: true` + `reason` and a partial dead-end route —
  clients MUST check `incomplete` (fixture recorded).

## Architecture (same seams as v1.2–v1.7)

`SpanshClient.plotGalaxy(req)` / `plotColonisation(req)`:

```ts
interface PlotGalaxyRequest {
  from: string; to: string;
  algorithm: string; cargo: number;
  useSupercharge: boolean; useInjections: boolean; refuelEveryScoopable: boolean;
  fuelPower: number; fuelMultiplier: number; optimalMass: number; baseMass: number;
  tankSize: number; internalTankSize: number; maxFuelPerJump: number;
  rangeBoost: number; reserveSize: number;
}
interface GalaxyWaypoint {
  system: string; jumps: number; distance: number; distanceToGo: number;
  fuelUsed: number; fuelInTank: number;
  neutron: boolean; scoopable: boolean; mustRefuel: boolean; mustInject: boolean;
}
interface GalaxyRoute { waypoints: GalaxyWaypoint[]; totalJumps: number; totalDistanceLy: number; totalFuel: number; }

interface PlotColonisationRequest { from: string; to: string; }
interface ColonisationWaypoint {
  system: string; jumps: number; distance: number; distanceToGo: number;
  bodyCount: number; scanValue: number; mappingValue: number;
}
interface ColonisationRoute {
  waypoints: ColonisationWaypoint[]; totalJumps: number; totalDistanceLy: number;
  incomplete: boolean; reason?: string;
}
```

Galaxy form: probe-verified names incl. fixed `is_supercharged:'0'`,
`use_injections_when_required:'0'`, `exclude_secondary:'0'`, `max_time:'60'`,
`supercharge_multiplier:'4'`, `injection_multiplier:'2'`; id64 resolution for
source/destination; inline-error check; poll guard completed-or-non-empty
`result.jumps`. Colonisation form: `source_system`/`destination_system` names
verbatim; same guards; map `incomplete: Boolean(result.result?.incomplete)`,
`reason` when present.

Host RPC `plotGalaxy`/`plotColonisation`; IPC `galaxy:*` and `colonisation:*`
(plot/start/clear/get/anchor + updated pushes); preload + EdhelperApi
(6 methods each); two tracker instances; `startExclusive` refactor; renderer
views `GalaxyPlotter.tsx` / `ColonisationPlotter.tsx` (sibling template,
uniform notice), cockpit cards, App pills 8+9.
