# ED Helper v1.15 — Sell Cargo (nearby market search)

**Date:** 2026-07-28
**Status:** Approved (Brian: "show where the best place nearby to sell your
current cargo, like a market search").
**Probe-verified** (findings "Commodity sell search" section; fixture
`commodity-sell-search.json`): `POST /api/stations/search` (synchronous, no
job) with `{filters, sort, size, reference_system}`; market filter
`{market:[{name:<DISPLAY name>, demand:{value:[min,max],comparison:"<=>"}}]}`;
`distance:{min,max}` (plain shape); sort
`{market_sell_price:[{name:<display>, direction:'desc'}]}`; results carry
distance, pads, type, market_updated_at (string) + the commodity row.
TRAPS: internal names (cmmcomposite) silently return count 0 — canonicalize
via `GET /api/stations/field_values/market` (cache per host run,
case-insensitive match); raw sort returns stale fleet carriers.

## Decisions

| Topic | Decision |
|---|---|
| Placement | 11th pill "SELL CARGO". Commodity select prefilled from `ship.cargoInventory` (each entry + editable free-text fallback), amount (prefilled with held count), radius (default 100 ly), max data age days (default 30), "Include fleet carriers" checkbox (default OFF). |
| Host | `SpanshClient.sellCargo(req: { commodity; amount; fromSystem; radiusLy; maxAgeDays; includeCarriers })` → canonicalize commodity via cached field_values (throw `Unknown commodity: <x>` if no case-insensitive match); search size 30, demand `[amount, 1e9]`, distance `{0, radius}`, reference_system, sell-price-desc sort; client-side: drop stale rows (`market_updated_at` older than maxAgeDays), drop carriers unless included (type contains 'Carrier'), compute padFit for the SHIP's pad size (S always true; M/L via pads fields — reuse the medium-fit test, L requires has_large_pad); return top rows `{ station, system, distanceLy, sellPrice, demand, updatedAt, padFit, stationType }` (keep ≤15 after filtering). |
| UI | Results table sorted as returned: station · system · distance · sell price (cr, bold) · demand · updated age · pad badge (NO M PAD red when !padFit, as in trade). Row count note when filters dropped rows ("hid N stale/carrier results"). Total value line: amount × best sellPrice. No tracker/exclusion (read-only, like DISTANCES). |
| Types/IPC | `SellCargoRequest/Row/Result` + response union; RPC `sellCargo`; IPC `sell:search`; api `searchSellCargo`; pad size passed in the request (from ship.padSize, default 'M'). |
| Release | v1.0.5. |
