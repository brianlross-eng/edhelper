# ED Helper v1.12 — Auto-update via GitHub Releases

**Date:** 2026-07-27
**Status:** Approved (Brian: repo public + full auto-update chosen over
notify-only). Repo flipped public 2026-07-27; unauthenticated releases API
verified (HTTP 200).

## Decisions (recommended defaults)

| Topic | Decision |
|---|---|
| Mechanism | `electron-updater` with the GitHub provider (repo brianlross-eng/edhelper). electron-builder gains a `publish` block; `npm run dist` then emits `latest.yml` + `.blockmap` next to the exes — a release must attach `latest.yml`, the Setup exe, and its blockmap for updates to resolve (portable exe is attached for humans but not part of the update channel). |
| Flow | Packaged app only (`app.isPackaged`). On ready: check + background download (autoDownload on). On `update-downloaded`: native dialog "Update ready — ED Helper <v> has been downloaded. Restart now / Later"; restart → `quitAndInstall()`, Later → applies on next quit (electron-updater default). All updater errors are logged and swallowed (offline must never break the app). No manual check UI in v1.12. |
| Structure | Thin `packages/app/src/main/updater.ts`: `initAutoUpdate(deps)` with injected `{ isPackaged, updater, showDialog, log }` so the wiring is unit-testable (check called only when packaged; dialog on downloaded; restart triggers quitAndInstall; errors swallowed). `index.ts` calls it in `whenReady`. |
| Unsigned builds | Supported by electron-updater for NSIS; no signing config. |
| Version | Bump to 1.0.2; release v1.0.2 with the update-channel artifacts. Full loop (installed 1.0.2 self-updating) is proven by the NEXT release; this phase validates the check phase live ("update not available" against v1.0.2 from the installed build's log). |

## Testing

Unit tests for `initAutoUpdate` (packaged gate, dialog on downloaded, restart →
quitAndInstall, error swallow). Live: install 1.0.2, confirm the updater log
reports a completed check. PR flow.

## Out of scope

Manual "check for updates" menu item, release notes in the dialog, delta
updates tuning, signing, portable-exe self-update (NSIS-only channel).
