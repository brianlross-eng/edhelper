# ED Helper v1.13 — Never return an unusable trade route

**Date:** 2026-07-28
**Status:** Approved (Brian: "Why give me this route, if I can't use it?" —
v1.11's warn-only UX replaced with automatic recovery).
**Builds on:** v1.11 pad verification (padFit annotation). Key game fact:
smaller ships land on bigger pads, so `requires_large_pad=1` routes are
GUARANTEED dockable for an M-pad ship. The trade API still has no
station-exclusion or medium filter (probe-verified), so recovery = re-plot or
truncate, never patch.

## Decisions

| Topic | Decision |
|---|---|
| Recovery chain (host, M plots only) | After annotation: if any hop `padFit === false` → (1) re-plot the SAME request with `requires_large_pad='1'` (server-guaranteed fit; skip pad verification) and return it marked `padAdjusted: { rejectedStops: n, mode: 'large-pad' }`. (2) If the re-plot throws or yields 0 hops → truncate the ORIGINAL route at the first `padFit === false` destination; if ≥1 hop remains, return marked `{ rejectedStops, mode: 'truncated' }` with totals recomputed. (3) If truncation leaves 0 hops → throw `No dockable route found for your Medium pad — try more capital, more hops, or a different start station.` |
| Types | `PlotTradeResult` gains optional `padAdjusted?: { rejectedStops: number; mode: 'large-pad' \| 'truncated' }`. |
| UI | Warning banner replaced by an INFO notice (muted style, not error) when `padAdjusted` present: large-pad → "ℹ Plotted large-pad stations only — the open plot routed through <n> stop(s) with no Medium pad."; truncated → "ℹ Route shortened: dropped <n> stop(s) with no Medium pad." The NO M PAD badge/warning code stays as a safety net but should never fire on returned routes. |
| Cost | One extra Spansh job (~20-90 s) only when the first plot had unusable stops. etaMinutes recomputed for whichever route is returned. |
| Release | v1.0.3 — which also live-proves the v1.0.2 auto-update loop on the installed app. |

## Testing

Host: bad-stop plot → second submit asserted with `requires_large_pad=1`, result marked large-pad (no station lookups on the retry); retry-fails → truncation with recomputed totals; first-hop-bad + retry-fails → error message. UI: both notice texts; no warning banner when padAdjusted. Live smoke: real M plot; if stops all fit (likely), assert no regression; the recovery paths are fixture-pinned.
