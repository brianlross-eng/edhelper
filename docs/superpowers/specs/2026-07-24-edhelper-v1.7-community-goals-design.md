# ED Helper v1.7 — Community Goals

**Date:** 2026-07-24
**Status:** Approved under the standing overnight authorization. Probe-verified:
Spansh's community-goals page calls **Frontier's own API** (not Spansh):
`GET https://api.orerve.net/2.0/website/initiatives/list?lang=en` → `{ activeInitiatives: [...] }`
(no auth; live-checked — currently `[]`, CGs are intermittent events). Field
contract extracted from Spansh's `objects/goal` normalizer in the JS bundle:
`title`, `bulletin` (HTML-ish text), `expiry` (UTC timestamp), `activityType`
(`"tradelist"` = trade CG), `target_commodity_list` (comma-separated string),
`starsystem_name`, `market_name`.

## Decisions (autonomous, recommended defaults)

| Topic | Decision |
|---|---|
| Placement | Seventh pill "COMMUNITY GOALS". Read-only viewer: fetch on tab open + a REFRESH button. No tracker/exclusion/cockpit involvement. |
| Source | `packages/app/src/host/frontier.ts` — a standalone `fetchCommunityGoals(fetchFn?)` (it's Frontier's API, not Spansh's; kept out of SpanshClient). URL overridable via `FRONTIER_API_URL` env for the host test. |
| Mapping | `CommunityGoal { title, system, station, activityType, isTrade, commodities: string[], expiry (ISO), bulletin }` — commodities split from `target_commodity_list` when `activityType === 'tradelist'`, trimmed; bulletin stripped of HTML tags. |
| Empty state | "No active community goals right now." — also today's live truth, which the smoke test exercises; the populated path is covered by a hand-built fixture matching the extracted contract. |

## Architecture

1. `frontier.ts`: `fetchCommunityGoals(fetchFn = fetch): Promise<CommunityGoal[]>` —
   GET `${FRONTIER_API_URL ?? 'https://api.orerve.net'}/2.0/website/initiatives/list?lang=en`,
   map `activeInitiatives`, throw on non-OK.
2. Host RPC `communityGoals`; IPC `cg:list` (ok/error wrap); preload
   `getCommunityGoals`; EdhelperApi method + `CommunityGoalsResponse`.
3. Renderer `CommunityGoals` view: fetch on mount, REFRESH button, goal cards
   (title, TRADE badge + commodity chips when isTrade, system · station, expiry
   as locale string, bulletin text), empty state, error state.

frontier unit tests (populated fixture mapping incl. commodity split + HTML
